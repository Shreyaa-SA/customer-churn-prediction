> **Predicts customer churn using Random Forest ML model on 7,043 telecom records, with customer risk segmentation.**

---

## 🎯 Key Results

| Metric | Value |
|---|---|
| Total Customers | 7,043 |
| Churn Rate | 26.5% |
| ML Model Accuracy | ~80% |
| Top Churn Factor | Tenure + Monthly Charges |

---

## 🛠️ Tech Stack
Python • Pandas • Scikit-learn • Random Forest • Matplotlib • Seaborn • Google Colab

---

## 🔍 Key Insights
- Month-to-month contracts have highest churn rate
- Fiber optic internet users churn more than DSL
- Customers with low tenure are highest risk
- Electronic check payment users churn most
